3 · 权限最小化核对

对 manifest 中每一项声明，用 grep 定位代码里的实际调用点，逐一比对"权限 → 用途"是否匹配。

权限判定实际调用点与用途
activeTab 匹配 调用点 popup/popup.js:146（tabs.query）与 :157（tabs.sendMessage）。仅在你点击扩展图标后，临时获得当前这一个标签页的访问权，用完即失效，不常驻。
storage 匹配 调用点 popup/popup.js:54 / :65，仅读写单个键 dse_settings_v1（几个布尔值/枚举值），使用 storage.local 而非 sync，不会同步到账号。
content_scripts.matches
chat.deepseek.com/*		 匹配 扩展功能的唯一操作对象。范围精确到单站点单路径前缀，未使用 <all_urls> 或通配符域。
host_permissions 空数组 显式声明为空。不申请任何常驻主机权限。
all_frames false 不在 iframe 中注入，避免覆盖页面内嵌的第三方框架。

刻意未申请的高风险权限（重点）

未申请的权限状态如果申请了会带来什么风险
<all_urls> / tabs未申请可读取你访问过的所有网站的 URL 与标题，构成浏览历史画像。本扩展改用 activeTab 替代。
cookies未申请可读取/篡改任意站点登录态，是账号接管的核心前提。
webRequest / webRequestBlocking未申请可监听并改写全部网络流量，即中间人能力。
downloads未申请可枚举并读取你下载目录中的文件。本扩展改用页面内 Blob + <a download> 触发一次标准保存，无法触碰其他文件。
clipboardWrite / clipboardRead未申请可静默读取剪贴板（可能含密码）。复制功能在扩展页内由你的点击手势触发标准 Clipboard API，无需该权限。
nativeMessaging / debugger / management未申请可跳出浏览器沙箱执行本机程序 / 接管调试协议 / 禁用或卸载其他扩展。
scripting未申请可向任意已授权页面动态注入代码。本扩展用 manifest 静态注入，并在发消息前校验目标 URL 必须匹配 https://chat.deepseek.com/，因此不存在"向任意站点注入"的能力。

4 · 敏感数据流分析

按「采集 → 存储 → 外传」三段追踪。

阶段具体行为判定风险与缓解
采集 读取当前会话已渲染的 DOM 文本（消息正文、代码块、表格、公式、图片链接）。触发条件：你点击导出按钮。不读取 cookie、localStorage、sessionStorage、表单、登录凭证。 功能必需 这是本工具的唯一目的。采集范围严格限定在"当前这一个会话"，不遍历会话列表、不枚举历史记录。没有任何凭证读取路径（grep cookie|token|apikey|password|Authorization 在运行代码中零命中），因此无法用于身份伪造或接口重放。
存储 持久化写入仅 1 处：chrome.storage.local['dse_settings_v1']，内容为偏好开关。不持久化任何对话内容。 低敏 设置项不含用户内容，可随时在 edge://extensions 中移除扩展一并清除。未使用 storage.sync。
外传 无。数据流向为：页面 DOM → 内存字符串 → 剪贴板 或 本机下载目录。二者均由你的点击触发，不经任何服务器。 无外传 见第 2 节穷举结论：代码中不存在任何可用于外发的 API。

声明一致性核验

把 README.md、SECURITY.md、manifest.json 的描述与代码实际行为逐条对比：

声明一致性核验依据
「全部处理在本机完成 · 不联网 · 不上传任何数据」一致第 2 节 URL 与网络 API 穷举结果支持该声明。
「不读取 cookie / localStorage」一致运行代码中零命中。
「不需要 downloads 权限」一致manifest 未声明；下载由页面内 Blob 触发。
「一次只导一个会话」一致导出入口只操作当前页面的滚动容器，无会话列表遍历代码。
声明与行为高度一致，这是可靠性的强证据——不少扩展的风险恰恰来自"文档说一套、代码做一套"。

检查项结果说明

未来演进观察点观察若后续加入「云同步」「账号登录」「在线转换」等功能，数据边界将发生根本变化。当前版本不具备这些能力，代码中也无相关预留。

7 · 结论与风险清单

等级风险点影响建议
低 扩展会读取当前会话的全部文本内容 这是功能本身。若把导出的 Markdown 分享出去，其中的对话内容（可能含隐私、内部信息）会一并外流。 仅在个人备份场景使用；分享前通读一遍导出文件。这是使用者行为风险，不是扩展缺陷。
低 tools/test-dom.js 使用 eval 与 jsdom 仅在你手动跑测试时执行，浏览器不加载；但若误将其打包进发布目录，会引入无谓的静态扫描告警与实际执行面。 打包时排除 tools/；已写入 README.md 与 SECURITY.md 的注意事项。
低 扩展本体无签名，需手动加载 加载来源完全依赖你本地目录的可信度。 不要把本目录交给不可信第三方后再加载；如需分享，请分享源码并让对方自行审阅后加载。
提示 无自动更新机制 DeepSeek 改版后规则可能失效，表现为导出不完整而非数据风险。 导出结果异常时先点「诊断」核对消息节点数与思考块数，再决定是否需要调整规则。

安装建议

  • 结论：可以安装。安全等级为「安全（低风险）」，无任何中高危发现。
  • 通过 edge://extensions/ → 开启开发人员模式 → 加载解压缩的扩展，选择本目录。切勿从第三方网站下载本扩展的打包版本。
  • 安装后到 edge://extensions/ 查看本扩展的「权限」详情，应只显示"读取和更改您在 chat.deepseek.com 上的数据"，不应出现"读取您的浏览记录"之类的提示。若不符，立即移除。
  • 如需进一步缩小信任面，可先只保留 manifest.json / src/ / popup/ / icons/ 再加载，并自行运行第 2 节的两条 grep 命令复核网络出口。
  • 导出内容涉及敏感信息时，优先使用「复制到剪贴板」而非下载文件，减少落盘副本。

8 · 评估方法学说明

本次做了什么：

  • 全文通读 7 个运行时代码文件（约 1,100 行），逐函数核对行为。
  • 用正则对 URL、网络 API、危险 API、遥测关键词、隐藏字符、最长行宽做穷举扫描。
  • 把 manifest 每一项权限与代码中的实际调用点（文件 + 行号）一一比对。
  • 核验 README / SECURITY.md / manifest 的声明与代码行为是否一致。
  • 确认无第三方依赖，因而不存在需要哈希比对的 vendored 库。
  • 用 jsdom 构造仿 DeepSeek 页面执行 36 项功能断言（含"用户消息恰好叫『思考过程』不得被误删"的护栏用例），验证解除器逻辑的正确性。

本次没有做（如实说明，避免过度承诺）：

  • 未做动态抓包验证（未在真实 DeepSeek 会话上运行时监控网络）——静态审计已穷举全部出口，结论可靠，但动态验证可提供额外佐证。
  • 未做二进制隐写分析（PNG 图标仅做了生成脚本可复现性核验，未做像素级熵分析）。
  • 未在真实 DeepSeek 页面上验证 DOM 结构识别规则的实际命中率——该站点需要登录态，且页面上线结构可能与本文模拟的结构存在差异。
  • 未评估 DeepSeek 站点的服务条款对"导出对话内容"这一行为的具体要求，使用者需自行确认合规性。
本报告基于 2026-09-26 的源码版本（v1.0.0）出具。代码后续若有改动，本结论需相应重新评估。
等级口径：安全 = 无恶意行为、无后门、无未授权外传、权限基本匹配；存在风险 = 有明确越权行为、可疑外传、严重可利用漏洞或依赖被篡改；不安全 = 确认恶意代码、后门或凭据窃取。本扩展判定为第一档。
